# PowershellTools

## AD Report Tool

Interactive WinForms GUI for querying Active Directory (Users, Groups, Computers, OUs).

```powershell
.\scripts\AD-Report-Tool.ps1
```

**Requirements:** Windows PowerShell 5.1+, ActiveDirectory RSAT module, read access to AD.

See script header comments for filter features (grouped AND/OR, CSV export, column chooser, schema merge).
